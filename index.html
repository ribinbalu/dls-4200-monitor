System Manual & Troubleshooting Guide

1. System Operation Manual

This is an offshore wireless temperature and humidity logging system designed for continuous 24/7 monitoring of the Mooring Drive Room.

  • Telemetry: Receives Sub-GHz LoRa packets (433 MHz, 62.5 kHz, SF11, CR 4/6) from the transmitter node and supports two-way remote TX commands.
  • Local Storage: Maintains a 5-day rolling history in LittleFS flash (capturing the first valid reading per hour, and marking NO DATA only after an entire hour elapses without data) and an independent alarm history matrix.
  • Cloud Sync: Automatically forwards live sensor metrics to ThingSpeak and Firebase every 60 seconds when Wi-Fi is active.
  • Network Provisioning: If the router changes or is offline, the device automatically hosts an open Wi-Fi AP named DLS4200-Config. Connect without a password to configure new credentials at 192.168.4.1.
2. Troubleshooting Tips
  • System Crash / Lockup: Use the TX CONTROL button to remotely reboot or soft-reset the Mooring Drive Room transmitter, or restart the receiver from the dashboard.
  • Radio Link Inactive / No Signal: Verify that the transmitter in the Mooring Drive Room has power and that its antenna is secure. The 3-tier LoRa watchdog auto-resets the SPI radio if silence exceeds the interval-scaled timeout.
  • Audio Alert Muted / No Sound: Modern browsers block autoplay audio by default. Tap the amber warning banner at the top of the screen to unlock the Web Audio API, or use the SOUND TEST button in the Alarm History modal.
  • Peak Temperature Reset: Hover to preview peak details; click the peak temperature indicator to speak details and open the password-protected reset modal.
  • Time Synchronization: Clearing 5-day logs, syncing device time (with spoken confirmation), and clearing alarm history require admin authorization.
